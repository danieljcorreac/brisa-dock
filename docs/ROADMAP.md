# Roadmap

## Current preparation

Maintain project-owned source/docs, contribution guidance, isolated checks and reviewable distribution. Keep the existing widget catalog unchanged.

## Distribution follow-up

- Maintain the public repository protections, required CI and private vulnerability reporting.
- Run CI on GitHub and inspect the actual result; local checks do not substitute for it.
- Create a draft Release, download its assets and test installation, update and rollback in isolation.
- Keep anonymous update verification covered by real public Release download checks.

## Coordinated user verification

Secondary-monitor reconnection, primary-display and DPI changes, suspend/resume, Explorer restart recovery, a full Narrator journey and sustained edge dragging in a long list remain physical checks.

## Later development

Additional real launcher/Steam cases, media and audio transitions, long sessions with real providers, and explicitly selected calendar integrations/automation. Commercial signing and new widgets are outside the current scope.
